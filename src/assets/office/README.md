# Office backgrounds

Drop photographs of offices / study rooms here (`.jpg`, `.jpeg`, `.png`,
`.webp`; 1280x960 or so is plenty, 4:3 or wider, nothing with people in it).
Each interviewer is given one by their id, and the room's tiles use it behind
the 3D head. With none here the app paints a blurred office instead.

Keep the licence of each file (and the author, where it asks) in
`CREDITS.md` next to this one.
